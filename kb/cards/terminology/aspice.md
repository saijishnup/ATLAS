Automotive SPICE is a process assessment model used to judge how mature a supplier's development processes are, in areas such as system and software engineering, verification, and project management. Assessments rate capability levels and are common in OEM-supplier contracts. It does not prescribe a lifecycle but expects defined work products and traceability. This tool does not include the model text, which is not redistributable.
