The manufacturer must identify and manage supplier-related risks for the vehicle type and show how the CSMS manages dependencies on contracted suppliers, service providers, and its own sub-organisations. Information must be collected through the supply chain to show these risks are managed. For a project with several suppliers this means cybersecurity responsibilities, evidence, and information exchange should be agreed in contracts and interface agreements, and requirements should state which party owns each security measure.
