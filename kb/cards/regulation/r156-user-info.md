The vehicle user must be able to be informed about an update before it is executed. The information covers the purpose of the update, including whether it is for recall, safety, or security reasons, any changes to vehicle functions, the expected time to complete, functions that may be unavailable during the update, and instructions that help execute it safely. After the update, the user must be able to be informed of success or failure, and of the changes made and any related user manual updates. These are user-interface and messaging requirements for any OTA feature.
