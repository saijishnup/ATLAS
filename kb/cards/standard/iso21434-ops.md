Continual cybersecurity activities include monitoring cybersecurity information, evaluating events, and managing vulnerabilities after release. Operations and maintenance cover incident response and updates to deployed items, including how a fix is delivered to vehicles in the field. This links to software update capability: the organisation must be able to ship and verify a security update quickly and safely. Projects with frequent updates need standing processes for triage, patch development, and release evidence, not only a one-time security review. Summary only: verify against the standard.
